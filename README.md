# AWS Data Analytics Services
 
## Overview
 
This repository contains hands-on exercises, notes, and practical implementations completed while learning AWS Data Analytics services. The focus of this repository is understanding how cloud-based tools can be used to ingest, process, store, analyze, and visualize data at scale.
 
The projects and documentation demonstrate foundational knowledge of modern data analytics architectures using Amazon Web Services (AWS).
 
---
 
## Repository Contents
 
### AWS Glue
**File:** `AWS Glue getting started.md`
 
AWS Glue is a serverless data integration service used for discovering, preparing, and transforming data for analytics, machine learning, and application development.
 
**Topics Covered:**
- ETL (Extract, Transform, Load) workflows
- Data Catalogs
- Crawlers
- Data transformation
- Data preparation for analytics
 
---
 
### Amazon EMR
**File:** `Amazon EMR Getting Started.md`
 
Amazon EMR provides a cloud platform for processing vast amounts of data using big data frameworks such as Apache Spark and Hadoop.
 
**Topics Covered:**
- Big Data Analytics
- Apache Spark
- Hadoop Ecosystem
- Distributed Computing
- Data Processing Workloads
 
---
 
### Amazon OpenSearch Service
**File:** `Amazon OpenSearch Service Getting Started.md`
 
Amazon OpenSearch Service enables real-time search, monitoring, and analysis of large datasets.
 
**Topics Covered:**
- Data indexing
- Search analytics
- Dashboard visualization
- Log analytics
- Real-time monitoring
 
---
 
### Amazon Redshift
**File:** `Amazon Redshift Getting Started.md`
 
Amazon Redshift is a fully managed cloud data warehouse designed for large-scale analytics and business intelligence workloads.
 
**Topics Covered:**
- Data Warehousing
- SQL Analytics
- Data Modeling
- Query Optimization
- Business Intelligence Reporting
