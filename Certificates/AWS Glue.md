# AWS Glue Getting Started
 
## Overview
 
AWS Glue is a fully managed, serverless data integration service that simplifies the process of discovering, preparing, transforming, and combining data for analytics, machine learning, and application development.
 
This practical introduced the core concepts of AWS Glue and demonstrated how organizations use ETL (Extract, Transform, Load) processes to prepare data for analysis and reporting.

## Key Concepts
 
### AWS Glue
 
AWS Glue automates many of the time-consuming tasks involved in data engineering, allowing users to:
 
- Discover datasets automatically
- Clean and transform raw data
- Create ETL pipelines
- Manage metadata through a centralized Data Catalog
- Prepare data for analytics and visualization
 
### AWS Glue Studio
 
AWS Glue Studio provides a visual interface for creating and monitoring ETL jobs without extensive coding.
 
Features include:
 
- Visual ETL development
- Job monitoring
- Workflow management
- Data transformation design
 
### AWS Glue DataBrew
 
AWS Glue DataBrew enables analysts and data scientists to prepare and clean data through a visual interface.
 
Capabilities include:
 
- Data profiling
- Data cleaning
- Data normalization
- Data transformation
- Feature engineering for machine learning
